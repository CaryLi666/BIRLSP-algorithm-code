# BIRLSP-algorithm-code

## A Brain-Inspired Reinforcement Learning algorithm with Stochastic Policy (BIRLSP) for sepsis prognosis

The schematic diagram of the BIRLSP model. For offline training, the BIRLSP model is trained on limited retrospective patient data. For online implementation, the clinician first checks the patient's status and then feeds the intervention decisions into the BIRLSP agent in treatment decision making. BIRLSP model predicts the state of the patient after treatment and returns the results to the clinician. Finally, the clinician assesses the treatment outcome.
